# TAMAYAK — Official Artist Website

A premium dark/cinematic artist portfolio starter inspired by the supplied reference screenshot, customized for TAMAYAK.

## Files
- `index.html` — main website
- `style.css` — complete responsive styling
- `script.js` — mobile menu, scroll reveals and contact-form UI
- `assets/` — place your real artist photos and cover artwork here

## Replace before publishing
1. Replace the CSS-generated portrait with your preferred TAMAYAK artist photo.
2. Replace the three release covers with actual artwork.
3. Change `href="#"` streaming/social links to your real URLs.
4. Connect the contact form to Formspree, Netlify Forms, your backend, or another email service.

## Run locally
Open `index.html` directly in a browser, or use any static web server.

## Suggested hosting
GitHub Pages, Netlify, Vercel, or your own web hosting.

## Included audio
The project includes the three uploaded MP3 releases: Pagar, Maratabat, and Alam Na 'Yan, Bro. The custom player supports play/pause, previous/next, seeking, volume, duration, and automatic next-track playback.

## V3 artwork
Actual uploaded TAMAYAK artwork is used for the hero and the three release cards.
